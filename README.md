# Gemini Tool Calling

Hands-on implementation of Gemini tool calling using the Google GenAI SDK.

## Implemented

- Custom function/tool calling
  - Gemini requests a custom function
  - Application executes the function
  - Function result is returned to Gemini
  - Gemini generates the final response

- Built-in Google Search tool
  - Gemini uses Google's Search tool
  - Search results provide current information
  - Gemini generates a grounded response

## Tech Stack

- Python
- Google GenAI SDK
- Gemini Interactions API
